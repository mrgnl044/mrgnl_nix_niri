# Configuration structure

- `flake.nix` wires hosts through `lib/mk-host.nix` and attaches Home Manager once.
- `host/<name>/configuration.nix` keeps only machine-specific imports and identity.
- `modules/profiles` groups reusable system layers.
- `modules/core` contains boot, Nix, locale, networking, and security basics.
- `modules/hardware` contains audio, Bluetooth, fonts, power, and GPU modules.
- `modules/desktop` contains login, Niri, and Noctalia system integration.
- `modules/packages` contains system-wide packages useful before Home Manager starts, split by CLI and GUI roles.
- `home/profiles` groups Home Manager layers.
- `home/common` contains shared theme tokens and desktop theme modules.
- `home/packages` contains daily user CLI packages split by task.
- `home/desktop` contains user desktop config generated by Home Manager.
- `home/programs` contains user terminal and application config.

Use system packages for tools needed by root or during recovery. Use Home Manager packages for daily user terminal tools and themed configs.
