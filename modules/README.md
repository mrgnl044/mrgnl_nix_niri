# System modules

This directory is for NixOS settings.

- `core` is boot, Nix, locale, networking, and security.
- `profiles` combines modules into reusable system layers.
- `hardware` is audio, Bluetooth, fonts, power, and GPU.
- `desktop` is login, Niri, and Noctalia system integration.
- `packages` is software available system-wide, including root and recovery shells.
- `networking` is explicit network services and VPN configuration.
- `users` is local user account setup.
