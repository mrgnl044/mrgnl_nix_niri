# Home Manager

This directory is for the `mrgnl` user session.

- `mrgnl.nix` is the Home Manager entrypoint.
- `session.nix` defines username, home path, state version, and environment variables.
- `profiles` groups user layers.
- `common` stores shared theme values.
- `desktop` configures Niri and Noctalia user files.
- `programs` configures individual applications.
- `packages` installs daily terminal tools by task.
