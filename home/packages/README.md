# User packages

Packages here are for daily terminal use and are split by task:

- `development.nix` for coding and GitHub workflows.
- `documents.nix` for Markdown, JSON, and readable terminal output.
- `monitoring.nix` for system inspection.
- `networking.nix` for DNS, HTTP, routes, ports, and connectivity.
- `shell-helpers.nix` for general command-line quality of life.
